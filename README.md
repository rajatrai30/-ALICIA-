# -ALICIA-
This one is a Desktop Based AI Virtual Assistant Application similar to Cortana but a more advanced one. Application is made using Python 3.9 and its Vast Existing Libraries.

Winner of XZIBIT 2023 and PHCET Tech-Expo 2022: A Python-based desktop AI virtual assistant with automation features, including security face detection, hand and iris tracker, email, SMS, WhatsApp automation and many more.
